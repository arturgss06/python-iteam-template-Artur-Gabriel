SUA RESPOSTA:

(
    Parâmetro padrão mutável (alunos=[]): Usar uma lista direto no argumento faz com
    que o Python reutilize a mesma estrutura em todas as chamadas da função, 
    o que acumula dados e gera bugs. O correto é definir como None e criar a lista dentro da função.

    Uso de range(len(alunos)): Percorrer a lista pelos índices numéricos deixa o código poluído. 
    É muito mais limpo e "pythônico" iterar direto nos elementos usando for aluno in alunos:

    Construção da lista com aprovados = aprovados + [...]: Usar o + recria 
    uma lista nova a cada repetição, o que pesa na memória. O método .append() é a melhor opção, 
    pois adiciona o elemento direto na lista existente de forma muito mais eficiente.
